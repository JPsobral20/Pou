# Pou – Augmented Reality

An augmented reality project inspired by the virtual pet game Pou, developed using Unity.

## Overview

This project explores the implementation of an augmented reality experience based on Pou.

## Technologies

- Unity
- C#

## Project Structure

- `Assets/` – Project assets and resources.
- `Packages/` – Unity packages and dependencies.
- `ProjectSettings/` – Unity project configuration.

## Getting Started

1. Clone this repository.
2. Open Unity Hub.
3. Select **Add Project** and choose the cloned project folder.
4. Open the project using a compatible Unity version.
